# Проверка маршрутов по моделям — 12 ноября 2026

Исправлена геометрия маршрутов на этажах 1–4. Использованы реальные модели,
отдаваемые backend, с тем же масштабированием и центрированием, что RouteEditor3D.
Локальные модели frontend отличаются от моделей backend: проверять нужно URL
из public scene API, а не произвольно выбранный файл GLB.

## Проверка и повторное применение

При соседних каталогах `frontend` и `backend`:

1. В frontend: `node scripts/inspect-route-models.mjs` — снимок активного графа и геометрии.
2. Из корня: `python frontend/scripts/render-route-audit.py` — проекции и маски коридоров.
3. `python frontend/scripts/plan-verified-routes.py` — план с проверенными подходами к магазинам.
4. `python frontend/scripts/render-route-audit.py --planned` — визуальная проверка нового плана.
5. В backend: `npx tsx prisma/apply-verified-routes.ts` — предварительная проверка.
6. Для применения установить `APPLY_VERIFIED_ROUTES=YES` и повторить команду.
7. `npx tsx prisma/verify-corridor-routes.ts` — проверка активной базы и публичного построения маршрутов.

Нужны зависимости обоих проектов, Python с Pillow и работающий backend :3000.
Снимки, план и отчёты создаются в соседнем `route-audit`; их не нужно публиковать.
Перед каждой записью сохраняется `route-backup-*.json` с исходными узлами и рёбрами.
Старые точки/рёбра отключаются, записи не удаляются. Якоря сохраняют идентификаторы.

Маска строится по верхней поверхности GLB: материал коридора `#d9d5e2` разрешён,
помещения, служебные блоки и атриумы запрещены. Новые рёбра проверяются с шагом
не более 0,25 единицы плана; разрешение самой маски — 1 единица. Это проверка
соответствия модели, а не подтверждение физических дверей на местности.
Подходы к входам сопоставлены со скриншотами 2ГИС; GLB содержит упрощённые границы
помещений. Для точности до дверного проёма требуется детальный план входов.

Результат проверки базы: 78 активных якорей, 0 дублей/осиротевших якорей,
323 активных соединения проверены по маскам, 0 выходов за коридоры.
78 публичных построений маршрутов прошли. Между блоками второго этажа путь
проходит по этажам 2 → 1 → 2; построение между ними только на этаже 2 возвращает 404.
Четыре неподтверждённых эвакуационных узла этажей 3–4 отключены с согласия пользователя.
Их необходимо проверить перед использованием приложения для эвакуационной навигации.
